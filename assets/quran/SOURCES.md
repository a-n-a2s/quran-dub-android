# مصادر بيانات القرآن والتفسير

ملف `quran_data.json.gz` بهذا المجلد هو دمج (merge) لمصدرين عامّين
موثوقين، مجهّز محلياً بسكريبت بايثون (غير مرفوع بالمستودع)، ومضغوط بصيغة
gzip ليبقى حجمه داخل APK صغير.

## 1. نص القرآن (الرسم العثماني)

- **المصدر الأصلي**: مشروع [Tanzil](https://tanzil.net) — نص موثّق ومُراجَع
  يدوياً على مصحف المدينة (طبعة حفص عن عاصم).
- **الترخيص**: Creative Commons Attribution 3.0 (CC BY 3.0).
- **طريقة الوصول**: عبر إصدار `ara-quranuthmanihaf` ("Quran Uthmani Hafs")
  من مستودع [fawazahmed0/quran-api](https://github.com/fawazahmed0/quran-api)
  (فرع `1`)، وهو نسخة مطابقة لنص الرسم العثماني الرسمي من مجمع الملك فهد
  (qurancomplex.gov.sa) بترميز Unicode قياسي.
- **عدد السجلات**: 6236 آية.

## 2. التفسير الميسر

- **المصدر**: "التفسير الميسر" الصادر عن **مجمع الملك فهد لطباعة المصحف
  الشريف** بالمدينة المنورة.
- **طريقة الوصول**: عبر إصدار `ara-kingfahadquranc` من نفس مستودع
  fawazahmed0/quran-api، المصدر الأصلي له Tanzil أيضاً (CC BY 3.0).
- **عدد السجلات**: 6236 آية (مطابقة تماماً لنص القرآن، تم التحقق برمجياً
  إنه كل آية إلها تفسير وبالعكس، بدون أي سجل ناقص).

## 3. معلومات مساعدة (الجزء / الصفحة / الربع / السجدة)

- من ملف `info.json` بنفس مستودع fawazahmed0/quran-api، وتشمل: رقم الجزء،
  رقم الصفحة بالمصحف المطبوع، رقم الربع (ruku)، رقم المنزل، وهل الآية فيها
  سجدة تلاوة.

## بنية الملف المدموج (quran_data.json.gz)

بعد فك الضغط (gzip)، الملف JSON بالشكل:

```json
{
  "version": 1,
  "surahs": [
    {"n": 1, "ar": "سُوْرَةُ الْفَاتِحَةِ", "en": "The Opening", "tr": "Al-Faatiha", "count": 7, "place": "meccan"}
  ],
  "ayahs": [
    {"s": 1, "a": 1, "t": "نص الآية بالرسم العثماني", "f": "نص التفسير الميسر", "j": 1, "p": 1, "r": 1, "m": 1, "sj": false}
  ]
}
```

المفاتيح مختصرة عمداً (s/a/t/f/j/p/r/m/sj) لتصغير حجم الملف؛ كود Dart بـ
`lib/data/quran_database.dart` بيحوّلها لأسماء حقول واضحة بجدولي SQLite
`surahs` و `ayahs`.

## لماذا هذا الاختيار

- النصّان (القرآن + التفسير الميسر) جايين من نفس العائلة المصدرية
  (Tanzil / مجمع الملك فهد)، وهذا يضمن مطابقة رقم الآية بين الاثنين
  بدقة 100% (تم التحقق برمجياً وقت التجهيز).
- "التفسير الميسر" بالتحديد هو المطلوب بخطة التطبيق (تفسير ميسّر ومختصر
  مناسب لعرضه مع كل آية بدون إطالة).
